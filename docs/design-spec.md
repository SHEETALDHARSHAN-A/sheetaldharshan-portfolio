# Design spec

- Palette: warm paper, near-black ink, acid green and orange accents.
- Typography: editorial serif display type paired with compact uppercase sans labels.
- Homepage: two-part composition; large statement on paper, sequenced introduction on ink.
- Projects: three-column desktop explorer with numbered selector, CSS preview stage, and project detail.
- Content: short, direct, evidence-based writing. No invented metrics or confidential work.
- Responsive behavior: explorer collapses to stacked selection controls; no desktop sidebar is forced onto mobile.
- Accessibility: semantic navigation, real buttons/links, visible focus through browser defaults, and `prefers-reduced-motion` support.
