# Implementation plan

1. Foundation: official Payload website template, PostgreSQL adapter, App Router, TypeScript, and pnpm.
2. Public shell: original visual system, conversational homepage, responsive project explorer, and editorial routes.
3. CMS model: projects, publications, homepage messages, appearance, and site settings.
4. Content integration: seed verified facts and query published Payload documents with a safe local fallback.
5. QA: typecheck, lint, production build, browser checks at desktop/mobile sizes, keyboard checks, and reduced-motion checks.
6. Production: configure managed PostgreSQL, persistent media storage, secrets, migrations, domain redirects, and backups.
