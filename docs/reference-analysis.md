# Reference analysis

## Julian Garnier

Observed on 14 October 2026. The homepage is intentionally sparse: a black canvas, compact rounded conversation bubbles, a typing indicator, and delayed message reveals. Navigation is embedded in the conversation instead of presented as a conventional hero and feature grid. The implementation uses the same interaction vocabulary—sequenced messages, typing state, concise links—but uses Sheetaldharshan's own copy, color accents, and layout.

## Yakudoo

Observed on 14 October 2026. The project index pairs persistent numbered navigation with a large visual stage and an editorial typographic system. Selection changes the project content while maintaining a strong sense of place. The implementation carries those principles into an accessible button-driven explorer and a responsive stage built from CSS, without copying source code, artwork, or personal branding.
